# 🔑 EasyJWT — Free, Private JWT Decoder & Troubleshooting Hub

**Instantly decode, inspect, and validate JSON Web Tokens. 100% client-side, zero data upload.**

👉 **[Open EasyJWT](https://www.easyjwt.top)**

![EasyJWT](https://www.easyjwt.top/api/og?title=EasyJWT&description=Free%2C%20Private%20JWT%20Decoder%20%26%20Troubleshooting%20Hub)

## ✨ Features

- **Instant Decoding** — Paste a JWT token and see header, payload, and signature immediately
- **Token Validation** — Check expiration status, algorithm, and claim integrity
- **Framework Guides** — JWT implementation guides for Express, Django, FastAPI, and more
- **Technical Blog** — In-depth articles on JWT security, authentication patterns, and best practices
- **100% Client-Side** — All decoding happens in your browser, tokens never leave your device
- **Zero Signup** — No account, no API keys, completely free

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **OG Images**: @vercel/og (dynamic Open Graph cards)
- **Language**: TypeScript
- **Deployment**: Vercel
- **Architecture**: Pure frontend, zero API costs

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/ToMyNorth/jwtdecoder.git

# Install dependencies
cd jwtdecoder
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
